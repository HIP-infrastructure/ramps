# RAMPS 

`ramps` is the repository for integrating the [Resections And Masks in Preoperative Space](https://github.com/cnnp-lab/RAMPS) pipeline into the HIP.

## Run the pipeline in the HIP

Once you have created a desktop and launched the RAMPS app, you will need to run the following command.
Make sure to replace the necessary paths.

```
ramps </Path_to/Pre-OP-Scan.nii.gz> </Path_to/Post-OP-Scan.nii.gz> </Path_to_Output_Folder_file_path/> <Output_Prefix> <Hemisphere> <Lobe>
```
